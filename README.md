# دفتر حساب — اپ اندروید

اپ واقعی اندرویدی که پیامک‌های بانکی رو می‌خونه، تراکنش واریز/برداشت رو تشخیص می‌ده، اعلان می‌فرسته تا بگی بابت چی بوده، و بعد درآمد/هزینه رو بر اساس حساب محاسبه می‌کنه.

## چطور بازش کنم و اجرا کنم

1. Android Studio رو باز کن (نسخه‌ی نسبتاً جدید — هر نسخه‌ی 2024 به بعد خوبه).
2. **File → Open** و پوشه‌ی `BankLedger` رو انتخاب کن (همون پوشه‌ای که این فایل توشه).
3. صبر کن Gradle sync تموم بشه (بار اول ممکنه چند دقیقه طول بکشه، چون باید کتابخونه‌ها دانلود بشن).
4. گوشیت رو با کابل وصل کن (یا از شبیه‌ساز استفاده کن) و دکمه‌ی Run (▶) رو بزن.
5. اولین بار که باز می‌شه، سه تا مجوز ازت می‌خواد: خوندن پیامک، دریافت پیامک، و نمایش اعلان. هر سه رو قبول کن — بدون اینا اپ کار نمی‌کنه.

اگه Android Studio پیشنهاد داد نسخه‌ی Gradle/AGP رو آپدیت کنی، لازم نیست قبول کنی؛ پروژه با نسخه‌های فعلی هم درست کار می‌کنه.

## اعلان به‌جای پاپ‌آپ فوری — چرا؟

اندروید (از نسخه‌های ۱۰ به بعد) اجازه نمی‌ده هیچ اپی از پس‌زمینه یهو یه صفحه/پنجره رو باز کنه، حتی برای خودش. این یه محدودیت امنیتیه که هیچ اپی (نه من، نه یه برنامه‌نویس دیگه) نمی‌تونه دورش بزنه بدون درخواست یه مجوز خیلی خاص و حساس که گوگل روزبه‌روز محدودترش می‌کنه.

راه استاندارد و قابل‌اعتمادی که اپ‌های واقعی (از جمله اپ خود بانک‌ها) استفاده می‌کنن، اعلانه: وقتی پیامک بانکی می‌رسه، یه اعلان فوری (heads-up) بالای صفحه ظاهر می‌شه — همون چیزی که موقع اومدن پیام تلگرام یا واتساپ می‌بینی. ضربه بزنی، اپ باز می‌شه و همون‌جا می‌پرسه بابت چی بوده. این تقریباً همون حسیه که می‌خواستی، فقط یک ضربه بیشتر داره.

اگه بعداً خواستی نسخه‌ی «واقعاً همیشه روی صفحه» (Overlay) رو هم اضافه کنیم، ممکنه — ولی به یه مجوز حساس‌تر نیاز داره که گوشیت باید جداگانه از تنظیمات بهش اجازه بده، و کاربرهای دیگه (اگه این اپ رو به کس دیگه‌ای هم دادی) معمولاً از دیدنش دلخور می‌شن چون شبیه اپ‌های مزاحم/تبلیغاتیه.

## تست بدون منتظرموندن برای پیامک واقعی

توی داشبورد یه بخش «تست دستی پیامک بانکی» هست — یه پیامک رو دستی بچسبون (یا از دکمه‌های نمونه استفاده کن) تا ببینی تشخیص و دسته‌بندی درست کار می‌کنه، بدون اینکه منتظر یه تراکنش واقعی بمونی.

## اگه فرمت پیامک بانکت فرق داشت

تشخیص پیامک توی فایل `app/src/main/java/com/rahim/bankledger/sms/BankSmsParser.kt` هست. اگه بانکت کلمه‌ها یا فرمت متفاوتی برای مبلغ/واریز/برداشت استفاده می‌کنه، یکی از پیامک‌های واقعیت رو (بدون شماره کارت کامل) بفرست تا Regex رو دقیق‌ترش کنم.

## نصب روی گوشی خودت (بدون نیاز به هیچ فروشگاهی)

برای استفاده‌ی شخصی لازم نیست جایی منتشرش کنی — همین که از Android Studio روی گوشیت Run بزنی، نصب می‌شه و همیشه می‌مونه (کابل رو می‌تونی بعداً جدا کنی).

## اگه بعداً خواستی به بقیه هم بدیش

- گوگل‌پلی برای اپ‌هایی که مجوز خوندن پیامک می‌خوان سخت‌گیره (فقط دسته‌های خاصی مثل اپ پیش‌فرض پیامک قبول می‌کنه)، جدا از اینکه گوگل‌پلی برای خیلی از کاربرهای ایرانی هم به‌خوبی در دسترس نیست.
- کافه‌بازار و مایکت معمولاً برای همین دسته از اپ‌های مالی/دفترداری که پیامک بانکی می‌خونن سخت‌گیری گوگل‌پلی رو ندارن، و مسیر طبیعی توزیع در ایران هم همینان.
- یا می‌تونی فایل APK رو مستقیم به هر کسی بدی تا نصب کنه (نیاز به روشن‌کردن «نصب از منابع ناشناس» توی گوشیش داره).

## محدودیت‌های فعلی

- داده‌ها فقط روی خود گوشی ذخیره می‌شن (بدون بک‌آپ ابری) — اگه گوشی عوض بشه یا اپ پاک بشه، داده‌ها از بین می‌رن.
- آیکون اپ فعلاً یه آیکون عمومیه؛ از Android Studio می‌تونی با **راست‌کلیک روی res → New → Image Asset** یه آیکون دلخواه بذاری.
- تشخیص پیامک برای فرمت‌های رایج بانک‌های ایرانی نوشته شده، ولی هر بانک جزئیات خودش رو داره — بخش قبلی رو ببین.

## ساخت فایل APK بدون نصب چیزی روی کامپیوتر خودت (گیت‌هاب اکشن)

این پروژه یه فایل `.github/workflows/build-apk.yml` داره که به گیت‌هاب می‌گه خودش پروژه رو بیلد کنه و فایل APK رو آماده‌ی دانلود بذاره — سرورهای گیت‌هاب این کار رو می‌کنن، نه کامپیوتر تو.

**مرحله ۱ — حساب و مخزن (repository) بساز**
1. اگه حساب گیت‌هاب نداری، توی github.com یکی بساز (رایگانه).
2. دکمه‌ی سبز **New** رو بزن، یه اسم بذار (مثلاً `bank-ledger`)، **Private** رو انتخاب کن، و **Create repository** رو بزن. فعلاً کاری به فایل‌ها نداشته باش.

**مرحله ۲ — کد رو بفرست گیت‌هاب (بدون نیاز به خط‌فرمان)**
1. برنامه‌ی **GitHub Desktop** رو نصب کن (desktop.github.com) و با همون حساب گیت‌هاب وارد شو.
2. زیپ پروژه رو یه جا باز (extract) کن.
3. توی GitHub Desktop: **File → Add local repository**، پوشه‌ی `BankLedger` که باز کردی رو انتخاب کن. اگه گفت «این یه مخزن گیت نیست، بسازیمش؟»، بله رو بزن.
4. پایین صفحه بنویس یه پیام کوتاه (مثلاً «نسخه‌ی اول») و **Commit to main** رو بزن.
5. بالای صفحه **Publish repository** رو بزن؛ همون اسمی که توی مرحله‌ی قبل ساختی رو انتخاب کن (یا بذار خودش با همون اسم پوشه بسازه) و مطمئن شو **Keep this code private** تیک خورده.

**مرحله ۳ — منتظر بیلد بمون و APK رو دانلود کن**
1. توی مرورگر برو به صفحه‌ی مخزنت روی github.com و تب **Actions** رو باز کن.
2. یه اجرا (run) با یه دایره‌ی زرد (در حال اجرا) می‌بینی؛ چند دقیقه صبر کن تا سبز بشه ✅.
3. روی همون اجرا کلیک کن؛ پایین صفحه بخش **Artifacts** یه فایل به اسم `BankLedger-debug-apk` داره — همونو دانلود کن. گیت‌هاب خودش این رو به‌صورت زیپ می‌ده؛ داخلش `app-debug.apk` هست.
4. اون فایل apk رو به گوشیت منتقل کن و نصبش کن (اگه گفت «نصب از منابع ناشناس» رو فعال کن، فعالش کن).

هر بار که بعداً کدی رو توی GitHub Desktop تغییر بدی و Commit و Push بزنی، این بیلد دوباره خودکار اجرا می‌شه و APK جدید می‌سازه.
